# **App Name**: Rượu Vang Cao Cấp

## Core Features:

- Homepage Hero Slider: Displays a rotating carousel of premium wine images with elegant taglines to capture user attention.
- Wine Catalog: Showcase available wines in a sophisticated grid layout, providing filters and sorting options for easy browsing.
- Product Detail Pages: Display wine specifics and tasting notes in a detailed format with an image gallery.
- Blog/Articles Section: Informative articles and updates related to wines with visually appealing cards.
- Contact Form: Simple contact form for user inquiries.  Contact messages will be stored in Firestore.
- Newsletter Subscription: Gathers email addresses for newsletters. Uses AI to generate personalized content. The LLM uses a tool to determine when or whether to add wines related to their past shopping experiences.
- Admin Dashboard: Management interface with secure authentication to manage the wine catalog, blog posts, and user inquiries.

## Style Guidelines:

- Primary color: Deep red (#8B0000) to convey luxury and sophistication.
- Background color: Cream (#FAF0E6), lightly desaturated from the primary color, provides a soft and elegant backdrop.
- Accent color: Gold (#FFD700), analogous to red, offers highlights and call-to-action emphasis.
- Headline font: 'Playfair', a serif with an elegant, fashionable feel, used for main headings.
- Body font: 'PT Sans', a sans-serif for readability in longer descriptions and articles.
- Elegant and minimalist wine-themed icons using 'lucide-react'.
- Responsive grid system that adapts fluidly across different devices, with focus on mobile-first design.
- Subtle transitions and effects for product hovers and page navigations to enhance user experience.
